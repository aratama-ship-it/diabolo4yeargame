# キャラクター画像の素材契約

このディレクトリは、主人公の表情とイベント話者の顔チップをゲームへ追加するための受け皿です。ゲーム側は実装済みなので、以下の契約どおりにPNGを置くだけで表示へ反映されます。画像が無いスロットは従来の絵文字または名前のまま表示され、1枚ずつ追加できます。すべて揃うまで待つ必要はありません。

> **2026-08-28 追記。** 顔はパーツ組み合わせ式のSVGアバター（[js/avatar.js](../../js/avatar.js)）で作る方針になりました。
> 表示は **PNG → SVGアバター → 絵文字/名前** の順に解決されるので、**このディレクトリのPNGは「上書き用」の位置づけ**です。
> ふだんはSVGアバターが出ます。特定のキャラだけ描いた絵を使いたくなったら、ここに置けばそのキャラだけPNGが優先されます
> （NPCを後々イラストへ戻す想定。本人の要望）。急いで用意する必要はありません。
> 設計は [docs/plans/2026-08-28-avatar-system-plan.md](../../docs/plans/2026-08-28-avatar-system-plan.md)。

## 置き場所と命名

- 主人公: `assets/chars/hero/mood-<状態>.png`
  - 状態は `best` / `good` / `normal` / `bad` / `worst` / `awaken` / `injured` の7種です。
  - 完全なパスは `hero/mood-<best|good|normal|bad|worst|awaken|injured>.png` です。
- イベント話者: `assets/chars/portrait/<キャラid>.png`
  - IDは `js/data.js` の `DATA.CHARACTERS` と完全一致させます。
  - 現在の対象IDは `coach` / `yota` / `mikoto` / `shion` / `kaito` / `irie` / `ujiji` / `kazuki` / `george` / `saito` です。
  - `youtube` と `malaysia` は人物ではないため作りません。
  - **`awaken` は主人公の表情キーであって話者IDではありません。** 「覚醒のきざし」イベントは
    演出用の擬似IDを使っており、ゲーム側も `DATA.CHARACTERS` に無いIDの画像は探しません。
    `portrait/awaken.png` を置いても表示されないので作らないでください（表情は `hero/mood-awaken.png`）。

## ファイル仕様

- PNG-32（アルファ透過）
- 正方形 512×512px
- 1枚60KB以下
- 正面から、またはわずかに3/4方向を向いたバストアップ
- 表示時は円形に切り抜かれるため、顔を中央に置き、四隅に意味のある要素を置かない
- 顔チップではディアボロを携行させない（物理的な持ち方・紐・スティックの拘束を避けるため）

## 画風と小サイズでの見え方

- ねんどろいど風・2.5頭身
- 既存キャラクター資産と同じ線の太さ・彩度に合わせる
- 実際の表示サイズは、ホームの顔44px、練習チップ18px、イベント64px
- 小さく表示されるため、細部を描き込みすぎず、顔・髪型・主要な表情が縮小後にも判別できるようにする

## 制作と承認の手順

制作前に次の既存手順と参照素材を確認します。

- `docs/reference/2026-07-14-character-consistency-workflow.md`
- `knowledge/character-consistency-refs/`

承認フローは `candidates` へ候補を出す → 本人承認 → `canon` へ確定素材を保存 → ゲーム表示用に切り抜く、の順です。

主人公の7枚は、表情によってイラストと絵文字が混在するのを避けるため、セットで揃えるのが望ましいです。ただし途中の状態でもゲームやレイアウトは壊れません。イベント話者も1枚ずつ追加して構いません。

画像を配置した後はブラウザをハードリロードしてください。コード変更は不要です。
