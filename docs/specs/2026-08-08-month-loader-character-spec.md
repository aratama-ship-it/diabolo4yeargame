# 月切替ローディングのキャラ画像 生成仕様

作成日: 2026-08-08
対象: 「４８ヶ月のディアボロ」の月切替ローディング（`showMonthTransition`）
関連: [js/app.js](../../js/app.js) の「切替演出のキャラクター」節、[css/style.css](../../css/style.css) の `.mt-chars` / `.mt-char`

ゲーム側の実装は完了している。**この仕様どおりの画像を `assets/loader/` へ置けば、コード変更なしでキャラ表示に切り替わる。**
画像が無い、または1枚でも欠けている場合は、従来のスティック＋紐のSVG装置へ自動で戻る（公開を止めないための設計）。

## 画面での使われ方

- 月が変わるたびに約1.5秒表示される。1周（24ターン）で24回出る。
- 並ぶ人数は学年連動。1年生=1人、2年生=2人、3年生=3人、4年生=4人。左から `performer-1` … `performer-4` の順。
- 動きは**7コマ×100msのコマ撮り**に乗せた左右の揺れのみ。**絵は部品に分けず、1枚のまま傾ける**。
  - 揺れ幅は±3.5px・±3度。人ごとに2コマずつ位相をずらしている。
  - `transform-origin: 50% 100%`（足元が軸）。そのため**足元が画像の下端に接している必要がある**。
- 人数が増えるほど自動で縮小する（1人=1.0、2人=0.92、3人=0.82、4人=0.72）。
- `prefers-reduced-motion: reduce` のときは1コマ目で静止する。

## ファイル契約

| 項目 | 決定 |
|---|---|
| 置き場所 | `assets/loader/` |
| ファイル名 | `performer-1.png` / `performer-2.png` / `performer-3.png` / `performer-4.png` |
| 形式 | PNG-32（**背景は完全透明。不透明背景・落ち影は不可**） |
| 寸法 | 縦560px前後・横は成り行き（実表示は高さ96px。3倍解像度でも足りる） |
| 重さ | **1枚40KB以下、4枚合計160KB以下**（超えるならWebP化かpngquantで圧縮） |
| トリム | 上下左右の余白は最小限。**足元＝画像の下端**、頭頂＝画像の上端に寄せる |
| 向き | 全員正面向き（横並びで見比べるため、顔の向きと大きさを揃える） |

現行素材（`knowledge/character-consistency-refs/characters/*/canon/*.png`）は**背景が不透明のグレー**なので、そのままでは使えない。切り抜きが必須。

## 絵の内容

- **ポーズ**: 両手にスティックを持ち、紐に乗ったディアボロを回している静止ポーズ。
  承認済みの `characters/浦和新/canon/master-with-diabolo-v4.png` と同じ構図・同じ立ち位置に揃える。
- **画風**: ねんどろいど風・2.5頭身。既存キャラ資産と同じ線の太さ・彩度。
- **人物の同一性**: 各キャラの `canon/turnaround-4view.png` を同一性の基準にする。
  手順書は [docs/reference/2026-07-14-character-consistency-workflow.md](../reference/2026-07-14-character-consistency-workflow.md)、
  キャラ資産の実体と台帳（`catalog.yaml`）は `knowledge/character-consistency-refs/characters/` にある。

## 必ず守る物理拘束（ここを外すと差し戻し）

`knowledge/character-consistency-refs/diabolo-physics-lock.yaml`（`status: user-approved-active`）に全面的に従う。特に:

- ディアボロ本体は**剛体**。カップ2つと中心軸は一直線上にあり、軸の伸縮・湾曲・カップの変形は禁止。
  手や紐に合わせて本体を変形させず、**直すのは手や腕やカメラの側**。
- 本数は固定: ディアボロ本体1・ハンドスティック2・連続した紐1本。
- **紐の前後関係**: 野中葵の3ディアボロ案v3は「紐がカップの手前に来ている」「スティックの比率が検証できない」を理由に
  `catalog.yaml` 上で `hard-rejected` になっている。**同じ失敗を繰り返さないこと。**
- スティックは1:1の比率が検証できる描き方にする（浦和新v4の承認履歴に準拠）。

## 生成の進め方（既存ワークフローに乗せる）

1. 生成物はまず `characters/<キャラ名>/candidates/` へ置く。いきなり `canon/` へ入れない。
2. `catalog.yaml` に `status` を記録する（承認前は `user-approved` を名乗らない）。
3. 本人承認が出たものだけ `canon/` へ昇格させる。
4. **ゲームへ入れるのは canon から書き出した切り抜き版**。`assets/loader/performer-N.png` は canon の派生物として扱う。

## 未決事項

- **登場させる4体が未確定。** 承認済みのディアボロ持ち絵は浦和新のみ。残り3体を誰にするか決める必要がある。
  候補は `catalog.yaml` にある10体（せいそん／将軍／ポチ／島広行／海里／野中葵／浦和新／田川ゆうき／子供ガーデン／成人女性ステージ衣装）。
- 決まったら、誰が `performer-1`〜`4` のどれかをこの節に追記する（左から並ぶ順＝1年生のとき出る人が `performer-1`）。

## 動作確認の手順

1. 4枚を `assets/loader/` へ置く。
2. `npm run build:web` を実行する（`assets/loader/` があれば `www/` へ同期され、無ければ「とばしました」と出る）。
3. ゲームを開き、行動を1回選んで月切替を出す。キャラが並んで左右に揺れれば成功。
   SVGのスティックと紐が出た場合は、4枚のいずれかが読み込めていない。
