## 現状診断（2026-08-28 実機プレビューで確認）

**磨かれている瞬間**（既にゲームらしい）:
- カードパック開封（浮遊・レア度発光・震え→フラッシュ→出現→バースト＋数字カウントアップ）
- 大会の順位発表（段階リビール・光バースト・メダルポップ）
- 覚醒／怪我の全画面スプラッシュ、月送りのディアボロ装置（TIDCオマージュ）

**平坦な瞬間**（体験の中心なのに演出ゼロ）:
1. **練習の成果画面** — 1周で24回見る最重要画面が、静的なテキスト表2枚＋余白8割。
   数字は一瞬で置かれ、大成功も失敗も同じ淡々とした行。ここが最大のギャップ。
2. **イベント画面** — 12人の名前付きキャラ（野中コーチ、志音、魁人…）が絵文字＋テキストのみ。
3. **ホームの主人公** — プレイヤーが名付けて4年間育てる主人公の姿が、絵文字の顔1個。
4. レーダー・ゲージが常に静止（成長ゲームなのに「伸びた」動きがない）。
5. タイトルの紙吹雪が完全静止（動きそうな見た目なのに動かない）。
6. 練習スロット装着・画面遷移にフィードバックがない。

## 設計メモ（design-web Step 1・5つの問い）

1. **誰が・どの場面で**: ディアボロ経験者・部活関係者がスマホ縦持ちで、すき間時間に1周を周回する。
   体験の中心は「行動選択→結果」を24回繰り返すループ。
2. **どんな気分に**: 「今月の練習が回った！」という手応え。数字が伸びる瞬間の快感で周回の単調さを中和し、
   卒業カードで「もう1周」につなげる。
3. **固有の核**: 実在のディアボロ文化（OIDC/AJDC/JDA採点/実在の技ジャンル）、物理拘束付きのディアボロ描写、
   ねんどろいど風キャラ資産、「おもちゃ箱パワプロ」のUI言語（インク縁取り＋ポップシャドウ＋紙吹雪）。
   → **演出言語を「ディアボロの物理」から作る**: 加速回転（カウントアップ）、キャッチの決め（ハンコ）、
   トス（出現の弾み）、紙吹雪（祝祭）。汎用エフェクトを足すのではなく、この語彙に限定する。
4. **踏襲するもの／外すもの**: 育成ゲー定型の「数字カウントアップ」「判定スタンプ」「リザルトの間」は踏襲
   （ジャンルの共通言語なので外さない）。外すのは、青紫グラデ発光・ガラス風・無関係なパーティクル乱舞。
   色も新色を足さず既存パレットの淡色チップで組む。
5. **守る機能条件**: 400px幅・ホーム1画面維持／**タップでスキップ可**（24回見るため）／
   `prefers-reduced-motion` 対応／Wave 1 は追加アセットなしで完結／イラストは欠落時フォールバック必須
   （ローダーの performer 方式を踏襲）／iOS PWA・Capacitor で動く素の CSS/JS のみ。

## Wave 1 — 「結果が回る」演出強化（アセット不要・Codex実装）

数値仕様はすべて [design/TOKEN_SHEET.md](../../design/TOKEN_SHEET.md) §5。

1. **練習の成果リザルト** （最優先）
   - 行が140ms間隔で下から入場 → 判定が淡色チップの**ハンコ**として押される
     （大成功=sun地で最も派手、失敗=coral縁＋着地後シェイク）→ 増分数字が**0からカウントアップ**。
   - 全行終了後にまとめカードがフェードイン、最後に「📈 今月の伸び 合計+N」ピルがポンと出る。
   - 画面のどこをタップしても最終状態へ即スキップ。reduced-motion時は演出なしで確定表示。
2. **ゲージ・レーダーが生きる**: ゲージ（体力・学力・構成 等）は挿入後に width が 0→実値へ伸びる。
   レーダーの値ポリゴンは表示のたび中心から開く（320ms）。
3. **タイトル紙吹雪の浮遊**: 静止している20片を±数px・±7degでゆっくり漂わせる（5.5〜8.5s周期で分散）。
4. **練習スロットの装着ポップ**: 装着した1枠だけがポンと弾む。3枠揃ったらGOボタンが一度だけ脈打つ。
5. **画面入場の統一**: `.screen` 表示時に180msのフェード＋8px上昇。イベント画面は本文→選択肢の順に80msずらす。
6. **reduced-motion 監査**: 新設アニメすべてを1つのメディアクエリで無効化。

やらないこと（Wave 1）: 音、ハプティクス、パック開封・順位発表・月送りの改変（既に良いため）、
ゲームロジック・数値バランスへの変更。
