## 本人が決めたこと（2026-08-28）

- パワプロ／Mii式に、目・髪などを組み合わせて2次元キャラを作れるようにする。
- 絵柄は**ハイブリッド**: 「分身（あなた）＝SVGベクター」「世界（先輩・タイトル・カード絵）＝今の塗り込み」。
- 使う範囲: **キャラメイク＋ホームの顔／卒業カード／卒業生名簿／NPCもこの仕組みで作る**。
- ただし **NPCは後々イラストに戻る可能性がある**。
  → だから **PNGを置いたらSVGプリセットを自動で上書きする**構造にする（後述）。

## なぜSVGか（設計判断の理由）

1. **パーツのズレが原理的に起きない。** 同じ `viewBox="0 0 120 120"` 上の座標で描くので、
   どの目とどの髪を組み合わせても合わない、が起こらない。
   AI画像生成でパーツを作る場合、ここが最も破綻しやすい工程だった。
2. **色が無段階に変わる。** 髪色・肌色・瞳色・服色は属性なので、色ごとの画像が要らない。
3. **1つの定義で全サイズに出る。** 18pxのやる気チップから300pxの卒業カードまで、
   追加素材ゼロで綺麗に出る。1体あたり**約2.9KB**（PNG方式なら数百KB〜）。
4. **既存UIと同じ言語。** このゲームはすでに3pxインク縁取り＋フラット塗りで、
   レーダーも月送りのディアボロもSVG描画。ベクターのほうが**むしろ地の絵柄に近い**。
5. **画像生成が要らない。** パーツ＝コードなので、生成AIの一貫性問題を回避でき、
   増やす・直すがその場でできる。

## 座標系（パーツを足すときはこの数字に合わせる）

```
viewBox 0 0 120 120 ／ 円形に切り抜かれる前提（半径60の外に意味のある要素を置かない）
  頭頂 16〜24    生え際 44〜48    眉 52    目 64    鼻 71〜73.5    口 79    あご 89    肩 92〜120
  目の中心 x=46（左）/ x=74（右）。左は同じ絵を scale(-1,1) で反転して置く。
```

**生え際を48より下げない。** 下げると眉が前髪に隠れる（2026-08-28に一度やらかして直した箇所）。

### 輪郭を作るときの制約（2026-08-29 作り直しで判明）

**頭のてっぺん側（y<52あたり）は、どの輪郭も同じ幅にしておく。**
前髪は x=26〜94 の一番広い頭に合わせて描いてあるため、ここを細くすると
髪が顔からはみ出して宙に浮く。**違いは「頬から下」＝顎の幅・顎先の形・顎の高さで出す。**
（実際の顔立ちの差もほぼ顎で決まるので、表現としても無理がない）

顎の高さは輪郭ごとに y=83〜95 と大きく変わる。**首はこの全部を吸収できる形にしてある**
（上は顎より十分高く、下は襟のV字を覆う幅まで広げた台形）。
顎を高くした輪郭で首元に隙間が出たのを直した箇所なので、輪郭を足すときは必ず確認すること。

### 目を増やすときの考え方（2026-08-29 追加）

当初の6種は**同じ楕円の回転・比率違い**だったため、並べても見分けがつかなかった（本人指摘）。
追加した6種は**輪郭の形そのものを変える**方針で作っている:

- てんてん … 白目を持たない点目。シルエットが根本から違う
- にっこり … 閉じた笑い目（線だけ）
- まつげ … 外側の上まぶたにまつげを足す
- するどい … 角のついた重い上まぶたを重ねる
- みひらき … 白目を広く、瞳を小さく
- ほしめ … 瞳が星型

**パーツを足すときは番号を詰めない（末尾へ追加する）。** 番号は保存データなので、
途中に挿入すると既存の顔が別人になる。

## 絵柄プリセット（2026-08-28 追加）

**「顔のパーツが少し大きい」という指摘を受けて、パーツの詰まり具合をまとめて切り替えられるようにした。**
輪郭・髪の形・パーツの種類は**全案で共通**で、変わるのは次の6つの数値だけ。

| 案 | 目の倍率 | 両目の間隔 | 口 | 線 | ねらい |
|---|---|---|---|---|---|
| いまの | 1.00 | 28 | 1.00 | 1.00 | 最初に見せた版（比較用の基準） |
| **ひかえめ ← 採用（2026-08-28 本人決定）** | 0.85 | 30 | 0.88 | 0.94 | 目を少し小さく、間隔を広げて落ち着かせる |
| あっさり | 0.72 | 31 | 0.78 | 0.86 | Mii寄り。線も細くして素っ気なくする |
| くっきり | 0.80 | 30 | 0.85 | 1.14 | パーツは小さく、線は太く。玩具っぽさを強める |
| スポーツ寄り | 0.74 | 31 | 0.84 | 0.90 | やや下寄りに配置して年齢感を上げる |

**「ひかえめ」で確定。** 他の4案は比較用に残す（消すと再検討のときに作り直しになるため）。

- 比較ページ: [design/avatar-styles.html](../../design/avatar-styles.html)
  （単体版は `node scripts/build-avatar-lab.mjs` で書き出す）
- **眉は目ほど縮めない**（`(1+目の倍率)/2`）。等倍で縮めると小さめの案で眉が消えてしまうため。
- メガネは目の位置・大きさに追従するので、どの案でもズレない。
- 決定したら `js/avatar.js` の `defaultProportion` を差し替える。**それ以外は変更不要。**

## 表情（パーツを増やさずに7状態を出す仕組み）

やる気5段階＋覚醒＋怪我を、**選んだ顔を保ったまま**表現する。

- **口**は7状態ぶん差し替える（表情の大半は口が担う）。
- **眉**は形を変えず、**外側の端の角度だけ回す**（-13度〜+12度）。これだけで喜怒哀楽が出る。
- **目**は極端な状態でだけ差し替える（絶好調＝笑い目／絶不調＝下がり目／覚醒＝見開き／怪我＝×）。
  好調・普通・不調では**プレイヤーが選んだ目のまま**なので、自分の顔だという感じが消えない。
- 追加演出: 絶好調＝ほお染め／覚醒＝背後に金の放射（既存の覚醒演出と同じ考え方）／
  怪我＝ばんそうこうを自動で付ける。

## 表示の解決順（全画面で共通・重要）

**PNG → SVGアバター → 絵文字/名前** の順で解決する。前回作った `mountCharImage` の受け皿を
そのまま活かし、その下にSVGを挟んだ形。これで「NPCを後々イラストに戻す」が
**PNGを置くだけ**で実現する（本人の要望）。

| 場所 | 導入前 | 現在 |
|---|---|---|
| ホームのやる気顔（44px） | 絵文字 | **自分のアバター（表情7段階）← Wave A 完了** |
| 練習メニューのチップ（18px） | 絵文字 | **同上（縮小表示）← Wave A 完了** |
| スカウト画面・登録確認 | なし | **顔の作成と確認 ← Wave A 完了** |
| イベントの話者（64px） | 名前のみ | NPCプリセット（Wave B） |
| 卒業カードの中央アート | 汎用SVG | 自分のアバター（Wave B。既存カード絵50種は残す） |
| 卒業生名簿・先輩イベント | 文字だけ | その先輩の顔（Wave B） |

## Wave A（完了・2026-08-28）

仕様と検証記録: [2026-08-28-avatar-waveA-spec.md](./2026-08-28-avatar-waveA-spec.md)

- 新入生スカウトに「顔をつくる」を追加。エディタは**縦にカテゴリ11種・横に候補**の一覧型で、
  候補サムネイルは「その候補だけを反映した顔」を出す（選ぶ前に結果が見える）。
- `state.avatar`（11個の数値）を保存。経歴の変更や引き直しでも顔は保たれる。
- **古いセーブ**はアバターが無くても `DT.avatar.fromSeed(名前)` で名前由来の顔が出る
  （セーブは書き換えず、表示時に解決）。
- npm test 257件全通過。ブラウザ実機で確認済み。

## Wave B（完了・2026-08-29）

仕様と検証記録: [2026-08-28-avatar-waveB-spec.md](./2026-08-28-avatar-waveB-spec.md)

- **卒業カード**: 既存のカードイラストはそのまま活かし、その上に**右下へ丸く顔を重ねる**
  （スポーツカードの選手写真と同じ構成）。左下の「ART: ○○」表記とはぶつからない配置。
  **PNG書き出しにも同じ顔を描く**ので、画面と共有画像が食い違わない。
  見本ギャラリー（カードの種類の一覧）には顔を出さない。
- **卒業生**: 卒業時に `avatar` をレコードへ保存。名簿の行と先輩イベントに顔が出る。
  導入前に卒業した先輩は名前由来の顔になる。
- **NPC 10人**: 役柄から手で決めたプリセット（`js/app.js` の `NPC_AVATAR`）。
  `youtube` / `malaysia` は人物でないので顔なし。
  **後からイラストに戻したくなったら `assets/chars/portrait/<id>.png` を置けばPNGが優先される。**
- npm test 263件全通過。

## 2026-08-29 の手直し（本人指摘）

- **候補の横スクロールを廃止**し、折り返しグリッドにした。
  横スクロールだと隠れた候補に気づけないため（`.apart-opts` を grid の `auto-fill` に変更）。
  余った幅は候補を大きくして埋めるので、サムネイルは56px→約65pxになり見やすくなった。
  全11カテゴリで横スクロールが出ないことを実機で確認済み。
- **目を6種→12種に拡張**（上記「目を増やすときの考え方」参照）。
- **「たれ」「つり」を「まる」へ統合**して目は10種に（本人指摘: 最初の3つが同じに見える）。
  楕円を十数度回しただけでは、この描画サイズでは差が出ない。傾きで character を出したいときは
  **回転ではなく、まぶたの形そのものを変えたもの**を末尾に足す（`するどい` がその例）。
- **輪郭を3種→5種に作り直し**、差を極端にした（本人指摘: 全部同じに見える）。
  あわせて `NPC_AVATAR` の番号を新しい並びへ付け直し、全10人が有効範囲であることを検証済み。

## 残っていること

- **NPCの顔は提案段階。** 気に入らない顔があれば数値を差し替えるだけで直る。
- 髪も同じ理由で増やす余地がある（前髪8・後ろ髪5）。目と同じく末尾に追加すればよい。
- **ゲーム内でキャラクターイベントが出たときの見え方が未確認**（発生率12.5%で自動確認に至らず。
  描画経路そのものは先輩イベントで実機確認済み）。テストプレイ時に見てほしい。
- パーツの拡充（目・髪を各2倍にすると振れ幅が出る）。
- スカウト画面の立ち絵、練習メニューのアイコン4種は受け皿も未着手。

## 開いていること（本人判断）

1. **どの絵柄プリセットにするか。** 上表の5案から選ぶ（または「もっと小さく」等の方向を指定）。
   既定はいま「ひかえめ」に置いてある。
2. **パーツを増やすか。** いまは各種3〜8。パワプロ的な密度にするなら目・髪をあと2倍は欲しい。
