## 0. コンセプト1行

「おもちゃ箱パワプロ」— インク縁取りの紙工作トイ感のうえで、**ディアボロの物理（加速回転・トス・キャッチ・紙吹雪）を演出言語**にする。
汎用キラキラではなく、回る・弾む・ハンコが押される、で気持ちよさを作る。

## 5. モーション（今回の中心・新設）

| トークン名 | 値 | 用途 |
|---|---|---|
| `--dur-tap` | 80ms | 押下フィードバック（既存 .08s を踏襲） |
| `--dur-pop` | 260ms | モーダル・チップ出現（既存 .26s を踏襲） |
| `--dur-row` | 380ms | リザルト行の入場（1行あたり） |
| `--stagger-row` | 140ms | リザルト行の時間差 |
| `--dur-stamp` | 340ms | 判定チップのハンコ演出 |
| `--dur-count` | 500ms | 数字カウントアップ（rAF） |
| `--dur-fill` | 450ms | ゲージの伸び（width transition, ease-out） |
| `--dur-radar` | 320ms | レーダー多角形の描画イン |
| `--dur-enter` | 180ms | 画面入場（fade＋8px 上昇） |
| `--ease-pop` | cubic-bezier(.34,1.56,.64,1) | 既存 pop-in と同じバウンス |
| `--ease-stamp` | cubic-bezier(.2,1.7,.35,1) | 既存 awaken-pop と同じ強バウンス |

### 数値仕様（実装はこの値のみ使う）

- **ハンコ**: scale 1.55→1・rotate -8deg→0（`--ease-stamp`）。失敗チップは着地後に ±4px 横シェイク 300ms を1回。
- **行入場**: translateY 12px→0＋opacity 0→1。
- **紙吹雪の浮遊**: translateY -4px↔+7px・translateX ±3px・rotate 基準角±7deg、周期 5.5〜8.5s（nth-childで分散）、無限 alternate。透明度は既存 .56 のまま。
- **レーダー描画イン**: 値ポリゴンのみ scale .55→1＋opacity 0→1（transform-box: fill-box / origin center）。
- **スロット装着ポップ**: scale .82→1.06→1、240ms `--ease-pop`。**装着した1枠だけ**に適用（全枠再生しない）。
- **合計ピル**: scale .4→1.12→1、`--ease-stamp`。
- `prefers-reduced-motion: reduce`: 上記すべて無効（最終状態を即時表示。カウントアップも確定値を即表示）。
- **スキップ**: 練習リザルトの演出中に画面のどこをタップしても最終状態へ即ジャンプ（周回で24回見るため必須）。

## 6. 実装への反映

- 新設モーショントークンは `css/style.css` の `:root` に `--dur-*` / `--ease-*` として追記し、
  keyframes・transition はトークン参照で書く（直書き値を散らさない）。
- 既存アニメ（pop-in / sheet-up / awaken 系 / パック開封）は据え置き。値を変える場合は先にこのシートを直す。

## 9. 文字の下限・ジャンルバー・見込み表示（2026-09-06 UXレビュー Wave 2 で追加）

Wave 1 は「触りやすさ」、Wave 2 は**「読める・判断できる」**。
新しい見た目を足すのではなく、**情報を減らして判断に効く数字へ置き換える**のがこの Wave の原則。

### 9-1. 文字サイズの下限（レビュー B1）

| 種類 | 下限 | 備考 |
|---|---|---|
| UIラベル・数値・バッジ | **.7rem（11.2px）** | iOS で実用的な最小の目安 |
| 説明文（何が起きるかを伝える文） | **.75rem（12px）** | 行動ボタンの説明・練習の補足など |
| 例外（情報を持たない装飾のみ） | 制限なし | 下記4つに限る |

**例外は次の4つだけ**（増やす場合はこのシートを先に直す）:
`.pcard-rarity` / `.pcard-artlabel` / `.pcard-num small`（カードの箔押し風ラベル。読ませる情報ではない）、
開発パネル `.dev-*`（本人専用）。

- 文字を上げるぶんの高さは **9-2 のバー置き換えで空いた分**から出す。新たに縦を伸ばさない。
- 短縮してよい文言は短縮する（例: 覚醒バッジ「🔥覚醒 あと3ヶ月」→「🔥覚醒 3ヶ月」）。
  **文字を小さいままにするより、語を削る。**

### 9-2. ジャンルバー `.gbar-*`（レビュー B3・ホームの小レーダー4枚を置き換える）

| 項目 | 値 |
|---|---|
| 行の列構成 | `3.2em（ジャンル名）／ 1fr（ゲージ）／ 2.2em（値）／ 2.8em（差分）` |
| 行の高さ | 26px（gap 4px）。4行＋見出しで **約 128px**（レーダー4枚 約190px から −60px） |
| ジャンル名 | .78rem / 800 |
| 値 | .95rem / `.num`（Baloo 2）/ 右寄せ |
| ゲージ | 既存 `.gauge` をそのまま流用（高さ12px・枠2px ink・地 #eef1fa） |
| 差分チップ | 背景 `#ffeec2`・文字 `--ink`・.7rem・角丸999・`▲6` の形。伸びが0または記録なしは `−`（`--ink-soft`） |
| 未解禁 | `🔒 3D+`＋空のゲージ＋差分欄に「未解禁」（.7rem `--ink-soft`） |

- **差分の意味は「先月の行動で伸びた分」**（先月の行動前の習熟との差）。今月まだ行動していない時点で見るので、
  「先月やったことの成果」がホームに残る形になる。
- **バー自体はタップ対象にしない。** レーダーは詳細画面に残し、そこからタップ拡大する。
  ホームの入口は既存の「技術 … 技術グリッド詳細 ▸」行（40px・Wave 1 で確保済み）ひとつに保つ。

### 9-3. 練習マスの見込み表示（レビュー C2/C3）

| 項目 | 値 |
|---|---|
| マスの高さ | 46px → **62px**（現在値の下に見込み、得意技があればさらに1行入るため） |
| 現在値 | 1.05rem `.num`（変更なし） |
| 見込み `.tg-gain` | .7rem / 700 / `--ink-soft`。`+3〜6`（最小と最大が同じなら `+4`） |
| 得意技の印 `.tg-fav` | .7rem・`--sun` 背景・`--ink` 文字のチップ「得意技+8」。**マスの中に置く**（はみ出させると下のマスに重なり見込みを隠す） |

- 見込みは **engine の実計算（`computeSlotGain`）をそのまま呼んで出す**。app 側で式を書き写さない。
- 幅は **普通〜大成功**。失敗（+0）は新技開発だけなので、表の下に1行だけ注記する。
- 得意技の補正は**数値に足さない**（1回の練習で1枠にしか乗らないため）。ただし**補正量は必ず書く**
  — 印だけだと見込みが実際とずれる（実測: インテグラル持ちの1DH×高難度技は見込み+2〜8に対し実際+10〜16）。
  伸びを抑える側のルール（例: ハイトスの新奇性-1）も同じ形で出し、背景だけ #ffe1d9 に変える。

### 9-4. 部門ボタンの自分の値（レビュー D2）

| 部門 | 出す値 | 補足ラベル |
|---|---|---|
| スペシャリスト（1DH/1DV/2D/3D+） | そのジャンルの習熟（`genreAvg`） | ジャンル名 |
| 個人総合 | 4ジャンル習熟の平均 | 「4ジャンル平均」 |
| テクニカル | 同上（12項目平均＝4ジャンル平均） | 「12項目の平均」 |
| パフォーマンス | `state.composition` | 「演技構成」 |

- 表示は `あなた 35`（.78rem・`.num`）＋補足（.7rem `--ink-soft`）。
- **これに置き換えて、エントリー画面の「参考: 現在の能力値」（表＋レーダー4枚）は消す**（G2 表の再掲を解消）。
- 演技方針ボタンは折り返さない2文字＋補足にする: `安全／通常／攻め` ＋ `ミスを減らす／練習どおり／難度を上げる`。
  `DATA.POLICIES` の `label` は保存・既存参照のため**変えず**、表示用の `short` / `sub` を足す。

### 9-5. 検証記録（2026-09-06）

- コントラスト実測（contrast.mjs）: `#2b3a67` on `#ffeec2` = **9.59:1** OK（差分チップ）。
  `#64719c` on `#ffffff` = 4.79:1 OK（`.gbar-flat` / `.gbar-lock` / `.tg-gain` の補助テキスト）。
- 実測（390×844）: ルート font-size は 16px。ホーム・練習・エントリー・詳細のいずれも
  **11.2px 未満の可視テキストは 0 件**。ホームはスクロールなしを維持。
- 静的テスト `Wave2: 文字の下限` が `.7rem` 未満を機械的に禁じている（例外5セレクタのみ許可）。
  **今後 `.7rem` 未満を足すときは、このシートの例外表を先に直すこと**（テストが落ちて気づける）。
