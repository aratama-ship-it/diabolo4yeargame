## 0. コンセプト1行

「おもちゃ箱パワプロ」— インク縁取りの紙工作トイ感のうえで、**ディアボロの物理（加速回転・トス・キャッチ・紙吹雪）を演出言語**にする。
汎用キラキラではなく、回る・弾む・ハンコが押される、で気持ちよさを作る。

## 5. モーション（今回の中心・新設）

| トークン名 | 値 | 用途 |
|---|---|---|
| `--dur-tap` | 80ms | 押下フィードバック（既存 .08s を踏襲） |
| `--dur-pop` | 260ms | モーダル・チップ出現（既存 .26s を踏襲） |
| `--dur-row` | 380ms | リザルト行の入場（1行あたり） |
| `--stagger-row` | 140ms | リザルト行の時間差 |
| `--dur-stamp` | 340ms | 判定チップのハンコ演出 |
| `--dur-count` | 500ms | 数字カウントアップ（rAF） |
| `--dur-fill` | 450ms | ゲージの伸び（width transition, ease-out） |
| `--dur-radar` | 320ms | レーダー多角形の描画イン |
| `--dur-enter` | 180ms | 画面入場（fade＋8px 上昇） |
| `--ease-pop` | cubic-bezier(.34,1.56,.64,1) | 既存 pop-in と同じバウンス |
| `--ease-stamp` | cubic-bezier(.2,1.7,.35,1) | 既存 awaken-pop と同じ強バウンス |

### 数値仕様（実装はこの値のみ使う）

- **ハンコ**: scale 1.55→1・rotate -8deg→0（`--ease-stamp`）。失敗チップは着地後に ±4px 横シェイク 300ms を1回。
- **行入場**: translateY 12px→0＋opacity 0→1。
- **紙吹雪の浮遊**: translateY -4px↔+7px・translateX ±3px・rotate 基準角±7deg、周期 5.5〜8.5s（nth-childで分散）、無限 alternate。透明度は既存 .56 のまま。
- **レーダー描画イン**: 値ポリゴンのみ scale .55→1＋opacity 0→1（transform-box: fill-box / origin center）。
- **スロット装着ポップ**: scale .82→1.06→1、240ms `--ease-pop`。**装着した1枠だけ**に適用（全枠再生しない）。
- **合計ピル**: scale .4→1.12→1、`--ease-stamp`。
- `prefers-reduced-motion: reduce`: 上記すべて無効（最終状態を即時表示。カウントアップも確定値を即表示）。
- **スキップ**: 練習リザルトの演出中に画面のどこをタップしても最終状態へ即ジャンプ（周回で24回見るため必須）。

## 6. 実装への反映

- 新設モーショントークンは `css/style.css` の `:root` に `--dur-*` / `--ease-*` として追記し、
  keyframes・transition はトークン参照で書く（直書き値を散らさない）。
- 既存アニメ（pop-in / sheet-up / awaken 系 / パック開封）は据え置き。値を変える場合は先にこのシートを直す。
